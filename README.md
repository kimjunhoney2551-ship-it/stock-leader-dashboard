- **필터의 한계:** 거래대금 미달은 기본필터 탈락으로 표시하지만, 관측값이 없으면 검증대기입니다. 베타는 장기 가격이력 확보 후 계산하고, 시총은 데이터 공급원에서 확인된 경우에만 필터링합니다. 과거 종가와 오늘 조회한 시총은 서로 기준일을 구분하며, 종합 COMP/재무/F-score는 별도입니다.
- COMP: 순위 모멘텀 40 (4/12/25/52주), 가격 모멘텀 25, 스마트머니 20, 밸류에이션 15. COMP ≥80 보존 → F-score → 복합점수 → 최대 10종목, 원유·정유·탱커 합계 30% 상한.
- 유니버스 전체 수집과 전 종목 COMP/F-score 확정은 다릅니다. 기관보유·13D/13G·재무증감 누락은 검증대기 처리합니다.
- **사용자 지정 예외:** 10월 9일 종가 스냅샷에도 최신 기관보유 공시를 사용할 수 있습니다. 가격 기준일, 기관 보유보고일, 실제 조회일을 각각 표시합니다.

## TradingView 재무지표 연결 확장 (2026-10-11)
- **선행 PER 혼합시점 추정:** 미국 2026-10-09 역사적 종가(Yahoo) / 2026-10-11 TradingView의 다음 회계연도 추정 EPS. EPS 추정이 양수면 forward PE에 반영하며, 0 이하 EPS는 적자기업 패널티(가치배점 0)로 처리합니다. 계산값은 2026-10-09에 알려진 전망치가 아니라 최신 추정치와 역사 종가를 결합한 값이므로, 같은 시점의 역사적 백테스트로 해석해서는 안 됩니다.
- **비교 가능한 FY 재무 데이터 추가:** 연결된 TradingView 연간 매출/매출총이익 2024년과 2025년 등의 같은 회계기간을 비교해 재무 데이터를 얻은 예비후보 228종목 전체에 조회를 시도해, 비교 가능한 209종목에서 매출 YoY 증가율과 GPM 개선폭을 산출합니다. 데이터 파일은 `docs/data/tradingview_financial_history_priority.json`이며, `docs/rules.html`, `docs/index.html`에서도 읽습니다. FY 비교는 TTM-FY 차이를 개선율로 오인하지 않습니다.
- **랭킹 모수:** COMP 백분위는 미국 전체 종목을 발견한 뒤, 시총 100억 원 이상, 거래대금 500만 달러 이상, β ≤ 2의 기본 필터를 실제 충족한 종목만으로 계산합니다. 기본필터에 필요한 자료가 없으면 검증대기입니다.
- **미확정은 미확정:** 기관보유 변화, 최근 13D/G, 영업이익 전기 대비 성장률, 전기 대비 SG&A/자산회전율 개선이 없는 경우 COMP 및 사용자 정의 F 4/4를 확정하지 않습니다. TradingView Piotroski 9점과 혼용하지 않습니다.
- **자동 갱신의 한계:** GitHub Actions는 매일 Yahoo 시세 업데이트를 시도하지만 ChatGPT에 연결된 TradingView의 인증을 GitHub에 전달받지 못합니다. TradingView 자료는 별도 일자 표기된 마지막 업로드 스냅샷이며 추가 자동화 연결 전에는 날마다 새로 갱신되지 않습니다.
